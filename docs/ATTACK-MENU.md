# 技能選單與 Code ZIP 驗收

2026-10-16，v1.3.3。

從 GitHub 預設分支 main 的 Code ZIP 原樣下載、解壓並透過 Start.bat 自我測試：修正前提交 `60c447d` 已含完整角色、技能與特效，374 項原有 WPF 檢查通過。未重現原始碼壓縮包缺少技能素材。使用者回報的完整操作情境尚未確認。

確定存在的使用障礙是小屋內技能一律反灰，其他限制也沒有原因提示。此次將右鍵與系統匣整合至 Request-Attack：小屋內明確標示「回桌面施放」，選招後先收合再交由原有桌面時間軸播放。安靜、計時、隱藏、拖曳及對話視窗限制保留，直接在兩種選單顯示原因；不自動更改偏好或停止計時。

新增實際 WPF MenuItem Click 與 WinForms PerformClick 事件測試：兩種選單的三招桌面施放、小屋收合後施放、六種阻擋原因、被阻擋時保留房間與計時，以及解除限制後恢復。源碼合計 407 項檢查通過，見 `attack-menu-integration.json`。這些測試呼叫正式 UI 事件處理，不代表實體滑鼠點擊驗收。

發布時再下載新的 GitHub Code ZIP 執行同組驗收，結果記錄於 GitHub Release。先前實體穿透、前景全螢幕、多螢幕 DPI 及休眠驗收限制仍適用。
