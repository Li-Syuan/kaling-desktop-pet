# 2.0 · 我們的小世界

完整解壓縮後雙擊 **Start.exe**，右鍵角色或系統匣 → **小世界 · 一起生活…**。原本的桌面／小屋角色會進入庭院，收合後回到原位置。新安裝預設蓮，庭院預設單人。

## 一起生活

「搭檔」可加入另一位不同角色，五位任意配對。「互動對象」決定喝茶、玩球、點心、招牌動作與習慣重設的對象；直接點角色也能摸摸。咖凌沿用目前穿的衣服。切換主角色或換裝會收合小世界，下次進入使用新選擇。

- 蓮：坐下擦劍、檢查劍刃、收刀、整理腰帶。
- 咖凌：制服整理蝴蝶結、睡衣整理衣領、帽 T 扶好帽緣，再伸展放鬆。
- 菇菇寶貝：小步靠近，壓低菇帽、歪頭探看。
- 緞帶肥肥：短腿小跑、急煞、得意扭扭。
- 綠水靈：壓扁蓄力、拉長起跳、落地回彈；維持黑圓眼裡的金色十字、細線圓球觸角。

開著「日常小劇場」時，角色會自行選擇劇場或使用擺設，活動間隔約 22–35 秒。常做的相處方式也會影響選擇。可以隨時用按鈕指定活動。

## 六段小劇場

| 劇場 | 發生什麼事 | 你可以介入 |
| --- | --- | --- |
| 擦劍與追球 | 蓮整理劍，小夥伴追球鑽進葉堆，頂著葉子回來 | 摸摸、拿點心；搬過葉堆後，追球路線也會改變 |
| 偷吃躲箱 | 肥肥偷吃餅乾留下碎屑，被發現後鑽箱裝睡 | 搬紙箱、拿點心引出來，或先幫忙清理 |
| 落葉小秘密 | 菇菇在角落蹲下、用葉子蓋住小秘密，夥伴好奇又退開 | 摸摸牠，或一起收拾 |
| 留一杯茶 | 拿出茶杯，等夥伴坐下，一起喝茶打盹 | 摸摸或拿點心，改變接下來的反應 |
| 紙箱讓座 | 先探頭躲進去，再讓位置給搭檔 | 拖動箱子會被發現；無效放置回原位 |
| 雨下共傘 | 開傘、靠近、甩甩水珠，一起看雨 | 摸摸、拿點心，或結束回庭院 |

沒有指定角色在場時，由目前夥伴演出符合自己姿態的版本；一位也能玩。新操作會取消未完成的互動。已完成的片段會記進原本的生活日記。

## 佈置與收藏

勾選「佈置庭院」，拖動家具至六個擺設區交換位置。也可選擺設 →「放進庭院…」→ 點位置；替換下來的家具仍可重新選用。中央保留走路通道，放在通道或邊界外會還原。紙箱在互動模式中拖曳，僅能放在中央可走範圍。

吊床能打盹、鞦韆能坐著晃、葉堆能躲藏、玩具籃能探索。水族箱展示在場兩位角色釣過的魚，花台展示種過的花，不會消耗原本的收藏。森林小菇、溪流寶石與貝殼由探險取得後才可擺放。

## 相處習慣與旅行

摸摸、喝茶、玩球和整理各自記錄，完成互動才增加；中途取消不算。每位角色分開保存，累積三次後開始影響自主活動。可以重設所選角色的習慣，不影響日記、衣裝和收藏。

森林與溪畔各有三個相遇事件，走到事件後選擇回應；完成整段才帶回一件紀念物。重複點選不會重複領取；取消、收合或換角時，未完成的旅行結束。帶搭檔時兩位都會留下旅行日記。

「拍下這一刻」只拍小世界自己的畫面，加入目前主角色的既有相簿，可從「查看相簿／一起玩」重看、另存 PNG 或刪除。每位角色仍最多 48 張。

## 照顧、暫停與更新

在庭院中，兩位在場角色各自使用既有電子雞狀態；便便會留在庭院並保存，可按「清理庭院」。想回小屋上廁所或洗澡時，先選互動對象，再按「回小屋照顧」。沒有出場的角色不消耗。

暫停、最小化和拖曳擺設會暫停小世界動作；探險期間暫停電子雞消耗。專注、安靜、全螢幕或手動隱藏會收合小世界，保留原本偏好與番茄鐘。關閉程式不計算離線消耗，每次啟動小世界都維持收合。

舊設定、照片、魚花收藏、角色造型與小屋都會保留。更新時關閉舊版，將新版全部解壓到新資料夾，雙擊 Start.exe；也可繼續使用 Start.bat。右鍵「版本 2.0.0 · 查看更新」開啟本專案 GitHub Releases，由你選擇下載，不會背景安裝。

原始圖與生成提示詞保存在 `assets/world/`，角色沿用已確認素材；新增場景、家具、蓮擦劍及咖凌三套動作使用內建 imagegen 製作。此為同人程式，非官方產品。
