# 蓮 · 梅影劍居

2026-10-16，v1.3.2。

蓮使用獨立的深木、白金與青綠房間：梅花圓窗、牆上掛劍與龍紋卷軸，以及梅紋小榻、青竹長椅、白金衣櫃、青瓷茶席、梅紋鞠球、行囊木箱。咖凌保留既有粉色素材。

以內建 imagegen 編輯既有房間與家具圖集，保持等角視角及家具朝向。新素材位於 `assets/room/ren/room.png`、`furniture.png`；完整提示詞在同目錄 `prompts.json`。原始生成圖片的 alpha 保留，家具圖集由 WPF CroppedBitmap 按 `assets/room/themes.json` 的矩形載入，沒有用程式重畫或改色。

角色目錄的 `roomTheme` 決定房間外觀。背景、六件家具、床與箱子的前景遮擋、視窗顏色、名稱、提示及日常台詞一起切換；圖片以主題與物件名稱快取。換角不建立第二間房、不顯示原本隱藏的視窗，不重設計時或玩具位置。兩角色共用房間布局與玩具位置。蓮的角色姿勢仍沿用日常動畫，沒有新增專用抱枕動作。

源碼 WPF 驗收通過 374 項檢查，包含原有 340 項及 34 項主題回歸檢查；詳細結果見 `ren-home-integration.json`。已檢視實際 WPF 渲染的床、長椅與木箱圖片，家具遮擋正確，未出現第二隻角色。這些是 WPF 渲染截圖，不是整個桌面的錄影。

實體穿透、真正前景全螢幕輪詢、混合 DPI 多螢幕及實際休眠仍保留既有驗收限制。解壓啟動器與 SHA-256 驗收另隨 GitHub Release 記錄。
