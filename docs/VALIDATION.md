# v1.3.0 驗證紀錄

執行環境：Windows PowerShell 5.1、WPF、Windows 原生視窗 API。測試使用獨立設定資料夾，不讀寫正式個人設定。

## 狀態與路徑

130 項檢查通過：既有計時、保存、恢復與點擊行為，v1.1／v1.2 設定升級、小屋與玩具位置往返、無效數值回退、重疊恢復、投影換算、玩具整個底部的邊界／家具判定，以及 81 組家具與邊界起訖點路徑。每段路徑包含起點／終點接合線，逐段檢查不穿過固定家具。

## 真實 WPF 視窗

開發環境整合測試通過 239 項檢查；計數會隨 Windows 是否允許安全的實體輸入測試而略有不同。下載包驗收結果以 integration-tests.json 為準。

- 三套服裝共 357 格載入；每套逐一走到三種點心、沙發、小床、紙箱與球，檢查共用材質來源和動作列。
- 睡覺停留末格；床上探頭後揉眼起床。檢查床與箱子的前後遮擋、紙箱藏身與冒出來、球被輕碰後滾動、得意表情。
- 衣櫃使用真正的 WPF 按鈕切換服裝；走路、睡覺、滾球、拖曳途中換裝會取消舊活動並維持單一角色。
- 展開／收合、小屋原生關閉按鈕及拖曳中退出整個程式；返回原桌面位置與模式，不留下第二隻。
- 有效／無效玩具拖放、保存、滾動撞邊界；拖曳時暫停追逐，放開後回應。
- 專注會取消追逐、阻止玩球和自主活動；安靜陪伴抑制自主活動。新的明確操作可以中斷自主活動；閒置睡眠會走到床上。
- 手動隱藏／全螢幕結果同時隱藏小屋與桌面，恢復時只顯示小屋；位置保存不包含自動展開狀態。
- 沿用餵食、番茄鐘、衣櫃、視線、桌面移動、快捷鍵註冊與訊息派送、系統匣恢復、全螢幕識別檢查。

檢視實際 WPF 畫面後修正了沙發入座高度、被窩遮擋和球與手的位置。room-window.png 為實際視窗內容；五段 animations/room/*.gif 是逐步執行同一個活動控制器、用 WPF 渲染錄製的連續動畫。可設定 KALING_RECORD_PREVIEW=1 再執行自我測試重錄原始影格。

## 未驗證與環境限制

- 不保證 Windows 允許測試視窗取得前景。若被拒絕，改測真實視窗的全螢幕判定及顯示控制，並在整合報告記錄未涵蓋的前景切換。
- 只有 OS 命中測試能確認是本程式的測試視窗時，才發送實體輸入。本次開發測試可驗證實體快捷鍵，但啟用穿透後沒有命中測試接收視窗，因此跳過跨程式點擊。此項未宣稱完成端到端驗證。
- 房間拖放測試呼叫實際 WPF 使用的拖曳處理函式，沒有強制對未確認前景的視窗發送實體拖曳。真實滑鼠長時間操作仍需人工使用回饋。
- 未實際拔插混合 DPI 螢幕或強制電腦睡眠；已測試負座標、越界、睡眠時間落差與重開恢復邏輯。
