# v1.8.0：十個可以親手玩的新功能

使用者目標：幫我想十個有趣的新功能去製作。
以目前 v1.7.0 五角色、角色目錄、照顧模型、小屋、設定備份與單一角色呈現為基礎。

| 功能 | 可以做什麼 | 完成證據 |
| --- | --- | --- |
| 1. 泡泡追逐 | 點破漂浮泡泡，角色追過去跳起來；30 秒短局、連擊、最高分 | 真實按鈕與畫布點擊、位置命中、逾時結算、紀錄保存 |
| 2. 接點心 | 用滑鼠帶角色接住掉落的餅乾，閃過小石頭；接到後有吃點心表情 | 移動邊界、碰撞、漏接與石頭扣分、完成與取消區分 |
| 3. 紙箱猜猜樂 | 看角色躲入其中一個箱子，箱子交換位置後猜在哪；三輪挑戰 | 洗牌時間與輸入鎖定、選箱揭曉、三輪結算 |
| 4. 池塘釣魚 | 下竿、等浮標、在提示時拉竿；魚種可收集 | 提早與錯過處理、成功釣獲、魚冊保存與重開 |
| 5. 盆栽花園 | 三種種子、澆水、發芽、開花和收成，離開不枯死 | 成長時間、澆水間隔、完成收成與保存；無離線懲罰 |
| 6. 節奏跳跳 | 看到節奏光圈收合時點擊，角色跳躍回應；十拍評分 | 完美／普通／錯過時窗、重複點擊無額外分、結果保存 |
| 7. 窗外天氣 | 晴天、雨、雪、星空可切換，場景與角色短句呼應 | 各天氣可見、偏好保存、安靜與隱藏暫停特效 |
| 8. 野餐時光 | 選點心組合後，看角色鋪墊、吃喝、看雲、休息的小連續劇 | 每階段動畫、選餐差異、結束一次入日記、取消不算完成 |
| 9. 拍照相簿 | 替目前角色／場景拍明信片，選相框與短句，PNG 可另存 | 只截本程式畫面、圖片重開可看、另存與錯誤處理 |
| 10. 生活日記與紀念章 | 記下遊戲、釣獲、花朵與野餐；完成條件解鎖小紀念章 | 真實事件產生日記、每日重複控制、每角色獨立、無空白獎章 |

## 共同行為

- 入口放在右鍵與系統匣的「一起玩」；新視窗用同一位角色，開啟期間隱藏桌面／小屋角色，關閉後回原本位置與模式。
- 保留角色原比例與眼睛、服飾；沿用既有動作，新增遊戲道具素材，不以任意變形替代動畫。
- 使用者開始遊戲才計時；沒有自動強迫遊玩，也沒有付費、抽卡或貨幣。
- 蓮三招與舊生活系統繼續可用。開始遊玩取消既有動作；角色切換、專注、隱藏與退出會正常暫停或關閉新活動，不能殘留第二位角色。
- 新功能存檔加入既有備份流程；舊設定直接升級，所有五角色各有日記、收集與最高分。
- 原始碼、實際 WPF、圖片／透明邊緣、解壓啟動器、GitHub Code ZIP 與發布資產均需驗證。
