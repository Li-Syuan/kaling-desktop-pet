- Windows 拒絕測試視窗取得前景，真實全螢幕前景輪詢未完整端到端驗證；幾何和手動隱藏狀態已測試。

- 未實測混合 DPI 多螢幕拖曳，未強制實機休眠；長時間間隙邏輯有驗證。
- 截圖為實際 WPF 渲染；動作採繪製姿態加關鍵影格變換，並非逐格手繪影片。
