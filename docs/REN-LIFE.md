# 蓮的日常 · v1.6.0

這一輪改善「放著不動很呆」：蓮的待機、摸頭與專注改用分層角色，讓視線、眨眼、耳朵、呼吸與髮尾能同時活動。

[60 秒新舊對照](../life-preview.html) · [直接播放影片](ren-life-comparison.mp4) · [Windows 下載](https://github.com/Li-Syuan/kaling-desktop-pet/releases/download/v1.6.0/KalingPet-Windows.zip)

![新舊對照](ren-life-comparison.png)

## 實際反應

- 呼吸約 3.8 秒一輪，眨眼間隔隨機約 2.8–6.8 秒，耳朵與髮尾有微小錯開的擺動。
- 滑鼠進入附近先移動視線，停留約 0.32 秒才轉頭；離開後多看約 0.65 秒，再平順回正。「看向滑鼠」可關閉這個反應。
- 按下滑鼠就有細微點頭回饋；雙擊與拖曳判定沿用原本規則。摸頭後保留六秒漸淡的放鬆神情，短時間反覆摸會稍微偏頭。
- 約每 20–50 秒選擇留意周遭、整理袖口、扶劍、短暫打盹或伸展，避開最近兩種動作。初次啟動約 20–35 秒出現第一次；「日常小劇場」可停用。
- 番茄鐘與安靜模式取消小動作及視線追逐，仍保留較輕的呼吸與眨眼。隱藏期間不累積動作，恢復後不會連續補播。
- 坐下、睡眠保留原姿勢並加上輕微呼吸。完成點心後會短暫保留放鬆表情；照顧系統的便意、如廁與洗澡優先。

四位角色、咖凌三套服裝、蓮三招劍術與小屋功能都保留。現有設定格式不變，不會重設番茄鐘或角色偏好。

## 本輪範圍

走路、點心、小屋及劍術仍使用原有逐格素材，並未重畫所有動作。分層待機與一般動作交界使用 160 毫秒平順淡入；拖曳、攻擊、換角、照顧或進屋會直接交還給對應活動，避免留下殘影。小屋仍使用既有角色畫面與遮擋方式。

本輪用 `RenLifeState` 管理經過時間、注意力、互動餘韻與自主間隔，`RenLifeVisual` 共用一份 WPF DrawingImage 畫頭、眼睛、耳朵、長髮與衣袖。所有動畫仍只有一個角色視窗。Dispatcher 目標間隔改為 16 毫秒；桌面移動改用經過時間計算距離，逐格動畫用累積時間避免每次延遲越積越多。16 毫秒是排程目標，不保證所有電腦實際達到 60 FPS。

## 素材與預覽

使用內建 imagegen，以現有 `assets/characters/ren/portrait.png` 作角色參考，生成 [分層素材](../assets/characters/ren/life-parts.png)。保留白髮紅眼、兔耳、白金衣裝、綠腰帶與佩劍。生成 PNG 原樣保留，執行時裁取部件並組合，不含外部下載或線上服務。

[完整生成提示詞](../assets/characters/ren/life-prompts.json) · [既有官方參考來源](REN-ASSETS.md)。這是同人生成素材，非官方拆出的遊戲資產。

對照影片使用實際 `Pet.Life.cs` 模型與 WPF 渲染器，由 `tests/Life.Preview.ps1` 輸出 1,800 格，再以 FFmpeg 封裝 60 秒 MP4。前半觀察待機，26 秒游標靠近，34 秒摸頭，40 秒離開，46–56 秒模擬專注。這是可重現的演出示範，不是螢幕錄影或顯示器 FPS 測量。

## 驗收

- 原有四角色、衣櫃、小屋、劍術及電子雞回歸，加上注意力先後順序、眨眼、20–50 秒排程、避免重複、摸頭餘韻、隱藏暫停、專注、拖曳、換角及淡入結束：**994 項 WPF 整合檢查通過**。
- **135 項設定檢查、44 項照顧模型檢查、13 項新角色存檔檢查通過**。
- 十分鐘加速模型演算驗證自主節奏與眨眼；30 / 60 次更新下的視線反應接近一致。
- WPF 實際渲染圖檢查深／淺背景、閉眼、摸頭、待機與小動作；模型及 DrawingImage 更新耗時另存 [量測檔](ren-life-render-timing.json)，不將它視為桌面 FPS。
- [完整整合檢查結果](ren-life-integration.json)。發行 ZIP 與 GitHub Code ZIP 的解壓啟動驗收紀錄列於 Release。

環境限制：Windows 拒絕測試視窗取得前景，因此全螢幕前景輪詢未完成端到端驗證；跨程序實體點擊、實體拖曳、混合 DPI 多螢幕移動、實際休眠喚醒未強行操作。測試已涵蓋對應的狀態切換、原生視窗旗標與 WPF 事件處理。
