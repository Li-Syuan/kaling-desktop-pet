# 蓮的日常 · v1.6.0

依使用者確認的楓之谷比例站姿延伸動畫。新的蓮使用完整角色姿勢，保留白髮紅眼、青色髮束與內耳、白金衣裝、綠腰帶和短身體。

[60 秒對照](../life-preview.html) · [互動圖鑑](../preview.html) · [Windows 下載](https://github.com/Li-Syuan/kaling-desktop-pet/releases/download/v1.6.0/KalingPet-Windows.zip)

## 動畫與互動

- 待機使用完整人物的連續小幅變形，呼吸約 3.8 秒一輪，隨機眨眼約 2.8–6.8 秒；耳尖和髮尾有細微錯開的擺動。
- 游標靠近先調整眼睛，停留約 0.32 秒後微微偏頭；離開後停留約 0.65 秒再回正。「看向滑鼠」可關閉。
- 按下即有微小回應。摸頭會閉眼放鬆，餘韻六秒漸淡；短時間反覆摸頭時偏頭幅度稍大。
- 每約 20–50 秒選擇留意周圍、抬手、蹲下扶劍、打盹或伸展，避免連續重複最近兩種。初次啟動約 20–35 秒開始。「日常小劇場」可關閉。
- 專注與安靜模式暫停注意力追逐和自主小動作，保留輕微呼吸眨眼。隱藏、進小屋與長時間停頓不累積待補動作。
- 走路、揮手、跳躍、三種點心、坐下、睡眠、伸展、提起、探頭、劍術、小屋和照顧反應均使用新造型。四位角色、咖凌三套服裝與原設定保留。

## 素材與實作範圍

[確認母圖](../assets/characters/ren/life/master.png)依[官方職業頁立繪](https://maplestory.nexon.co.jp/job/anima/len/)與[官方宣傳插畫](https://g.nexonstatic.com/media/m2sndzne/1366x768-ren-the-red-eyed-wanderer-wallpaper-maplestory.jpg)製作。後續均以這張母圖為參考，使用內建 imagegen 生成完整姿勢。[完整提示詞](../assets/characters/ren/life/prompts.json)。

16 個完整關鍵姿勢由 WPF 套用小幅位移、翻轉和旋轉，產生 24 組動作、104 個播放影格；不是 104 張逐張重畫的原畫。坐姿與睡姿另行生成，避免素材表的髮尾重疊。透明來源圖原樣保留，載入時擷取各自相連的角色，不組裝不同頭、身體和耳朵。

待機、摸頭及專注使用同一張人物圖的連續變形與局部表情替換。一般動作以關鍵姿勢播放，切換使用短暫淡入；拖曳、攻擊、照顧及換場可中斷。坐下和睡眠有細微呼吸。房間沿用現有家具遮擋，尚未新增專用抱枕和鑽被窩原畫。

Dispatcher 排程目標 16 毫秒，移動依實際經過時間計算；不保證所有電腦實際顯示達到 60 FPS。[模型與繪圖更新耗時](ren-life-render-timing.json)不等於螢幕 FPS。

## 驗證

- 998 項 WPF 整合檢查：四角色／衣櫃／劍術／小屋／電子雞回歸、16 姿勢獨立載入、素材邊界、104 格與渲染器一致、照顧反應共用新造型。
- 注意力先後、眨眼、自主間隔、避免重複、互動餘韻、專注、隱藏、拖曳及角色切換。
- 十分鐘加速模型演算；30 / 60 次更新的注意力收斂一致性。
- 實際 WPF 深淺底圖與桌面畫面檢查；[整合結果](ren-life-integration.json)。
- Release ZIP 與 GitHub Code ZIP 另經解壓啟動器驗收，詳見 Release 紀錄。

限制：未強行取得 Windows 前景或送出跨程序實體點擊，因此全螢幕前景輪詢、實體拖曳、混合 DPI 多螢幕與實際休眠喚醒仍未完成實機驗證；相應狀態切換及事件處理已有自動檢查。

## 重建

執行 tests/Build-RenArt.ps1，可用與執行版相同的 WPF 渲染器重建 atlas 與頭像。tests/Life.Preview.ps1 接受 OutputDirectory 與 ReferenceAtlas 參數，後者指向 v1.5 atlas.png；生成 1,800 格後以 FFmpeg 封裝 60 秒影片。左側為桌面版 v1.5，並非楓之谷官方原圖。
