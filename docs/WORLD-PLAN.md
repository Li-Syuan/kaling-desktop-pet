# v2.0.0 · 楓之谷桌面小世界

## 交付範圍

- 可收合的小世界：原角色及可選搭檔同場，五位任選不同角色，咖凌沿用三套服裝。初次預設單人。進出小世界不複製角色、不改桌面位置或番茄鐘。
- 每位角色有連續準備、動作、收尾的招牌動作；使用確認過的原作比例。蓮整理與擦劍，咖凌整理蝴蝶結與伸展，菇菇壓帽探頭，肥肥短腿急煞與扭扭，水靈壓縮起跳與落地回彈。
- 可中斷、分支的小劇場：擦劍與追球、偷吃躲箱、落葉秘密、一起喝茶、紙箱讓座、雨下共傘。角色點擊、移箱、誘餌、清理造成可見的後續變化。自動活動有間隔，不連續重複。
- 可佈置的小屋庭院：六個預設擺設區與保留通道；吊床、鞦韆、葉堆、玩具籃、水族箱、花台及探險紀念物可拖放，無效放置還原。魚與花讀取 v1.8 各角色收藏。角色能使用擺設。
- 本機相處習慣：依摸頭、喝茶、玩球、清理等實際完成的互動記錄，影響自主活動，提供查看與重設。不上傳、不監視別的程式、無離線消耗。
- 兩條短程探險（森林、池塘）：可帶搭檔，三個可點選事件與不同回應，完成後帶回紀念物。中斷不發獎，重複點擊不重複入帳，紀念物可擺設並觸發新反應。
- 新增可重建的 Windows EXE 啟動器、版本顯示與開啟官方 GitHub Releases 的更新入口，保留 BAT/VBS；無背景更新或下載執行。

## 整合與驗收

保留既有桌面、小屋、技能、電子雞與十種玩法；新增 world 狀態，沿用 schema 3 與原子存檔備份。小世界自行管理雙角色畫面與照顧，專注／安靜／隱藏時收合，未選角色不消耗。每次啟動仍收合。

驗收涵蓋五位與三套服裝、所有不同角色配對、連續動作、故事分支、擺設邊界、收藏連接、習慣保存、探險中斷與單次獎勵、視窗生命週期、舊存檔與損毀復原。實際 WPF 截圖與預覽，EXE/BAT、發布包與 GitHub Code ZIP 解壓啟動均檢查。實機無法驗證項目保留明確紀錄。
