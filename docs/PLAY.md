# 一起玩 · 十種小日子

雙擊 `Start.bat`，右鍵角色或系統匣 → **一起玩 · 十種小日子…**。新視窗會接替桌面或小屋的角色；按「收好，回去陪你」或關閉視窗，就回到原本的位置與模式。

| 玩法 | 操作與完成條件 |
| --- | --- |
| 泡泡追逐 | 按開始後點漂浮泡泡；角色跑過去跳一下。30 秒結算，連續命中有加分，點空白會中斷連擊。 |
| 接點心 | 滑鼠左右帶著角色接餅乾、閃灰色石頭。30 秒結算；接滿三塊且允許進食時，完成後算吃一塊餅乾。 |
| 紙箱猜猜樂 | 記住探頭的箱子，四次交換後點箱子。共三輪，每猜中一次 100 分。 |
| 池塘釣魚 | 按「下一竿」，等浮標沉下與「拉竿」提示，1.25 秒內按按鈕、點畫面或空白鍵。可收集粉紅魚、藍紋魚、金色魚、小海星；太早或錯過都不算釣獲。 |
| 盆栽花園 | 點三個花盆之一，選種子、種下、澆水。每次水量 90 秒，上限 180 秒，兩次澆水至少隔 20 秒。累積 240 秒有水的在線陪伴就開花，按收成加入收藏；缺水只停止生長。 |
| 節奏跳跳 | 金環與縮小光圈重合時點畫面或按空白鍵；十拍結算。誤差 0.14 秒內 100 分，0.30 秒內 50 分。每拍只能計分一次。 |
| 窗外天氣 | 選晴天、下雨、飄雪或星空；所有新玩法場景共用並記住選擇。這是手動場景，不查詢真實天氣。 |
| 野餐時光 | 選餅乾或布丁，20 秒內依序鋪墊、吃點心、喝茶、看雲、打盹。完整結束才入日記，且在允許進食時增加一份點心。 |
| 拍照相簿 | 選姿勢、相框、32 字以內短句，按拍照。照片只包含程式自己的場景。每位角色最多 48 張，可重看、另存 PNG、刪除；改完姿勢後可再拍新照片。 |
| 生活日記與紀念章 | 完成遊戲、釣魚、收花、野餐、拍照與日常照顧才記錄。保留最近 100 篇，同一天相同事件不重複灌水；畫面顯示最近 8 篇。 |

紀念章共 12 枚：第一次遊玩、泡泡 200 分、接點心 150 分、猜箱三次全對、第一尾魚、四種魚、第一朵花、三種花、節奏 800 分、完整野餐、第一張照片、五個不同日期的互動。五日陪伴不需要連續登入。

## 保存與中斷

- 蓮、咖凌、菇菇寶貝、緞帶肥肥、綠水靈各有獨立進度；咖凌三套衣服共用咖凌的紀錄。
- 「暫停」會停止當局時間與操作計分；最小化遊玩視窗也停止當局。花園在角色在線時繼續生長。
- 切換玩法、角色、摸頭、換裝、回小屋、施放劍術、手動／全螢幕隱藏會取消未完成遊戲。開始番茄鐘或安靜陪伴時結束遊玩；再次開啟不接續未完成的一局。
- 遊玩期間暫停原本電子雞消耗及便便顯示；結束後繼續。沒有離線懲罰、每日任務壓力或貨幣。
- 花園在關閉程式、專注、安靜或隱藏時不生長、不缺水；未選用角色也暫停。
- 舊設定自動升級，保留原服裝、位置、照顧及番茄鐘。新資料位於既有 `%LOCALAPPDATA%\KalingPet\settings.json`，照片在同目錄的 `photos` 子資料夾。

## 素材與預覽

[離線玩法預覽](../play-preview.html) 展示實際 WPF 畫面；遊戲在 Windows 程式中操作。角色沿用已確認的原作比例，綠水靈維持黑圓眼內金色十字。新魚、花、浮標與野餐道具使用內建 imagegen 產生透明圖集，提示詞保存在 [assets/play/prompts.json](../assets/play/prompts.json)，原始 PNG 與裁切座標一併保留；場景、泡泡及光圈由 WPF 繪製。
