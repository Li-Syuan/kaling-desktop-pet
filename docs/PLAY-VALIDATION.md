## 可重跑

完整解壓縮後執行 `Start.bat --self-test`，輸出獨立臨時資料夾中的 `integration.json`。純模型可用 Windows PowerShell 執行 `tests/Play.Model.Tests.ps1`；其他三個模型腳本同樣在 `tests` 目錄。

發布流程另會檢查 ZIP CRC、逐檔內容、解壓後啟動器，以及從 GitHub 重新下載的 Code ZIP。對應資產 SHA-256 和最終啟動結果記於 v1.8.0 發布頁，不把尚未執行的包裝檢查算入上表。

## 環境限制

Windows 未允許測試視窗取得前景，因此未完成跨程序真實滑鼠穿透與前景全螢幕自動偵測的端到端驗證。實體拖曳、混合 DPI 多螢幕、強制休眠／喚醒也未測；這些項目只跑正式事件處理器、位置邊界及時間間隔邏輯。遊戲點擊的命中由相同遊戲模型驗證，並未注入實體滑鼠。

所有新玩法使用既有角色影格與 WPF 場景；本版沒有新增五角色的逐格手繪角色動畫。天氣是手動視覺選擇，不連網取得氣象。
