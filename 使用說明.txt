咖凌 · Windows 桌面寵物

啟動
1. 如果拿到 ZIP，請先「全部解壓縮」。
2. 雙擊 Start.vbs，咖凌就會出現在桌面右下角。
3. 也可以雙擊 Start.bat。請保留資料夾中的 pet.ps1 與 spritesheet.png。

操作
・滑鼠左鍵拖曳：移動咖凌。
・點一下：揮手；點兩下：跳躍。
・右鍵：動作、留在原地、自由散步、跟著滑鼠、視線追蹤、大小設定與關閉。
・預設留在原地，並在滑鼠靠近時看向滑鼠。
・關閉：右鍵選「關閉咖凌」。
・再次啟動同一份寵物不會重複開啟。

動畫圖鑑
雙擊 preview.html，可離線查看九組動作與十六個視線方向。
animations 資料夾包含各組 GIF、全部動作 GIF / MP4，以及待機→跳躍→待機的預覽。

執行環境
Windows 10 / 11 內建 Windows PowerShell 5.1 與 WPF，不需要安裝 Python 或 Node.js。
程式完全離線，不讀取你的文件，也不連網、不加入開機自動啟動。
啟動器的 ExecutionPolicy Bypass 只適用於這次執行，不會永久修改系統設定。

檔案
spritesheet.png：透明 PNG，1536×2288，192×208 格，九組動作加十六方向，共 73 格。
pet.ps1：可檢視的桌面程式原始碼。
validation：素材與動畫檢查報告。
若啟動失敗，請查看同資料夾內的 pet-error.log。
