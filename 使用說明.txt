# 咖凌 · Kaling Desktop Pet

紅髮異色瞳的 Windows 桌面夥伴。v1.1 加入摸頭、餵食、陪伴番茄鐘、心情泡泡與日常小劇場，也會記住你喜歡的位置和設定。

![摸頭與餵食](docs/feeding.png)

## v1.1 陪伴日常

- **摸頭與點心**：點頭部摸摸、點身體揮手、雙擊跳躍；右鍵餵餅乾、布丁或茶。每種點心都有台詞，互動冷卻避免連續刷屏。
- **陪伴番茄鐘**：25 分鐘專注、5 分鐘短休息，每四輪 15 分鐘長休息。可調整為 1–180 分鐘、暫停、繼續或取消；下一階段需要手動開始。睡眠或重開後保留進度並暫停，不自動增加完成輪數。
- **心情泡泡與小劇場**：繁體中文時段台詞，約每 8–15 分鐘出現一次。專注、全螢幕與安靜陪伴時不自發打擾；重要的番茄鐘提示仍會顯示，預設無聲。
- **記住偏好**：位置、尺寸、移動方式、視線、泡泡及番茄鐘設定會保存。螢幕移除後會嘗試將咖凌放回可見區域。
- **不擋工作**：所在螢幕有前景全螢幕視窗時自動隱藏；滑鼠穿透和系統匣選單讓操作更方便。

## 下載與啟動

1. 從 Releases 下載 `KalingPet-Windows.zip`，選擇「全部解壓縮」。也可以用 GitHub 的 Code → Download ZIP。
2. 雙擊 `Start.vbs`。若系統不支援 VBScript，請使用 `Start.bat`。
3. 咖凌會出現在桌面右下角；右鍵選單可設定動作、模式、大小或關閉。

Windows 10 / 11，使用系統內建 Windows PowerShell 5.1 與 WPF，不需 Python、Node.js 或安裝程式。啟動器只為當次程序指定 ExecutionPolicy Bypass，不修改永久執行原則。不連網、不讀取個人文件、不加入開機啟動。

## 操作

| 操作 | 功能 |
| --- | --- |
| 左鍵拖曳 | 移動位置 |
| 點頭部／身體 | 摸頭／揮手，等待系統雙擊間隔後回應 |
| 點兩下 | 跳躍 |
| 右鍵 | 餵食、番茄鐘、動作、移動與尺寸、泡泡、安靜陪伴與關閉 |
| `Ctrl+Alt+K` | 開啟／關閉滑鼠穿透 |
| `Ctrl+Alt+H` | 顯示／隱藏咖凌 |
| 系統匣咖凌選單 | 恢復互動、控制番茄鐘、叫咖凌回來或退出 |
| 開啟 `preview.html` | 離線查看九組動作和十六個視線方向 |

預設留在原地。重複啟動不會產生第二隻。快捷鍵被其他程式占用時會提示，仍可使用系統匣。若找不到咖凌，選「叫咖凌回來」會恢復互動、移回主要螢幕並暫時關閉自動隱藏；可從右鍵重新開啟自動隱藏。

## 設定與升級

先從系統匣關閉舊版，再解壓縮新版啟動。v1.0 沒有偏好存檔，首次升級使用預設值。

個人設定與錯誤紀錄位於 `%LOCALAPPDATA%\KalingPet`，不會放進 GitHub 或下載包。`settings.json` 採安全替換寫入並保留 `.bak`；損壞設定會另存 `.corrupt-*` 再使用預設值。番茄鐘每十秒保存進度，正常關閉時也會保存；意外斷電最多可能少記最後十秒。程式關閉時不繼續計時。

「心情泡泡」和「安靜陪伴」控制可選的對話；番茄鐘完成、暫停與操作恢復提示屬於必要提示。全螢幕或手動隱藏時所有泡泡都不顯示，計時仍繼續，狀態可從系統匣查看。

## 素材與程式

- `pet.ps1`：可檢視與修改的 Windows / WPF 程式。
- `lib/`：設定與計時邏輯、Windows 原生視窗支援。
- `tests/`：可重跑的狀態與桌面整合測試。
- `spritesheet.png`：透明 PNG，1536×2288，單格 192×208，共 73 格。
- `animations/`：各動作 GIF、整體 GIF / MP4 及十六方向展示。
- `docs/`：動作接觸表、視線圖與驗證摘要。

九組動作為待機、向右移動、向左移動、揮手、跳躍、失落、等待、思考、檢查。視線以十六個方向切換。

本專案是獨立 Windows 桌面程式；它不會讀取 Codex 聊天狀態。Codex 原生寵物使用另外的本機寵物套件。

## 驗證與限制

Windows PowerShell 5.1 / WPF：29 項狀態測試及 57 項整合檢查通過，包含 73 格素材、互動與冷卻、計時流程、設定驗證、原生快捷鍵註冊、訊息派送、系統匣恢復、全螢幕視窗尺寸判斷、隱藏恢復與日常小劇場。詳細結果見 [驗證紀錄](docs/VALIDATION.md)。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\State.Tests.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\pet.ps1 -SelfTest
```

自我測試使用獨立暫存資料夾，不改個人設定；會短暫開啟測試視窗。在能確認滑鼠指向本程式的測試區域時，測試會模擬快捷鍵和滑鼠點擊，再還原游標。若桌面不允許此操作會記錄未驗證項目。

本次環境拒絕測試視窗取得前景，也無法將滑鼠命中目標確認為測試視窗，因此**真實前景全螢幕切換、實體按鍵輸入與跨程式點擊穿透尚未端到端驗證**；不同 DPI 的實體多螢幕切換與實際電腦睡眠也未實測。網頁圖鑑保留既有模擬 DOM 檢查，未新增實際瀏覽器視覺驗收。
