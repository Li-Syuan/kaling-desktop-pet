咖凌與蓮 v1.3.1（Windows 整合版）
1. 關閉舊版，將 ZIP 全部解壓縮，雙擊 Start.vbs 或 Start.bat。
2. 右鍵 → 角色 → 蓮；衣櫃只顯示當前角色衣裝。
3. 右鍵 → 劍術 · 蓮 → 花瓣斬、殘影連斬、龍影大招。系統匣也可操作。
4. 點頭摸摸、點身體揮手、雙擊跳躍、拖曳移動，餵食與番茄鐘照常使用。
5. 專注計時或安靜陪伴時停用攻擊；拖曳、換角、隱藏可取消特效。
6. Ctrl+Alt+K 切換滑鼠穿透；Ctrl+Alt+H 顯示／隱藏。
7. preview.html 是離線互動動畫圖鑑。
設定存於 %LOCALAPPDATA%\KalingPet，自動沿用舊版；已包含生活小屋。
此為 Windows 獨立程式，不是 Codex 原生 Pets 套件。

生活小屋使用方式

1. 從系統匣關閉舊版，將下載包全部解壓縮。
2. 雙擊 Start.vbs，或改用 Start.bat。
3. 右鍵咖凌 → 打開生活小屋；系統匣也有入口。

點床休息，睡著後點床或咖凌叫醒；點沙發抱枕放空。
點茶几選餅乾、布丁或茶。點衣櫃換裝，關閉衣櫃後繼續生活。
球和紙箱可以拖動，必須完整留在空地，放錯會退回原位。
點球會輕碰；拖動球放開後會短距離滾動。點紙箱會躲貓貓。
點咖凌摸摸頭，偶爾得意歪頭。新的操作可中斷上一個活動。
回桌面或關閉小屋視窗只收合小屋；退出程式請選系統匣「關閉咖凌」。

三套服裝全部支援小屋。右鍵可切換安靜陪伴與日常小劇場。
日常小劇場開啟時約 30–60 秒自主活動；五分鐘沒操作會回床。
番茄鐘進行中不追球、不自發玩鬧。小屋位置和玩具位置自動保存。
每次重新啟動小屋預設收合。舊設定、服裝與桌面位置繼續沿用。

Ctrl+Alt+K：桌面滑鼠穿透（小屋保留互動，回桌面後套用）。
Ctrl+Alt+H：顯示／隱藏桌面或小屋。
系統匣「叫咖凌回來」可收合小屋、恢復操作和桌面位置。
preview.html：離線動畫圖鑑與五段實際小屋互動預覽。
詳細功能及驗證限制見 README.md、docs/VALIDATION.md。
此為 Windows 獨立桌面程式，與 Codex 原生 Pets 分開使用。

蓮的小屋互動沿用日常動畫，尚無專用抱枕／被窩素材。劍術請回到桌面施放。
